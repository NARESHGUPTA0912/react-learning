# ⚛️ React Learning

This repository contains my React learning journey, covering core concepts like components, hooks, state management, and hands-on mini projects.

Built using React with Vite for fast development and optimized performance.

---

## 🚀 Tech Stack

* React.js
* JavaScript (ES6+)
* HTML5 & CSS3
* Node.js (for tooling)

## 🛠️ Getting Started

### 1️⃣ Clone the repository

```bash
git clone https://github.com/NARESHGUPTA0912/react-learning.git
```

### 2️⃣ Navigate to project

```bash
cd react-learning/react-app
```

### 3️⃣ Install dependencies

```bash
npm install
```

### 4️⃣ Run the app

```bash
npm start
```
